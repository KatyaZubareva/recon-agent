# Использование AI

## Агент и настройки
- Агент: Claude Code (десктоп-приложение, вкладка Code), модель Claude Opus 5.5 (`claude-opus-5-5`).
- Режим разрешений: обычный — агент спрашивает подтверждение перед командами и изменениями.
- Инструкции для репозитория: [CLAUDE.md](CLAUDE.md).
- Правила для агента: маленькие коммиты, push только с подтверждения, суммы без float,
  mock не выдаётся за 1С, план перед большими изменениями.

## Примеры применения
1. **Подготовка репозитория.** Агент перенёс в репозиторий только папку `fullstack` стартового
   комплекта, сделал первый коммит без изменений, прочитал условие и пересказал требования —
   пересказ я сверила с `fullstack.pdf`.
2. **1С в Docker.** Агент собрал образ сервера 1С 8.3.27 под amd64, предложил схему
   `ibsrv` + `ibcmd` вместо кластера с Apache, написал модули HTTP-сервисов и `onec/restore.sh`.
   Объекты конфигурации я создала в Конфигураторе по пошаговой инструкции агента.
   Агент подбирал недокументированный формат публикации `ibsrv` на тестах и сам находил ошибки:
   `РольДоступна()` в базе без пользователей возвращает Ложь, у методов HTTP-сервисов есть
   отдельное право «Использование», выгруженная роль ПолныеПрава была пустой.

## Где я исправила или дополнительно проверила решение агента
- **Публикация загрузчика.** Агент предложил защищать HTTP-сервис ReconLoader только
  правами (роль ПолныеПрава), оставляя его опубликованным. Я потребовала, чтобы в рабочем
  режиме он не публиковался вообще: `restore.sh` перезапускает `ibsrv` только с ReconAPI и
  проверяет, что загрузчик отвечает 404.
- **Импорт и сверка — отдельные действия.** Агент запланировал одну кнопку и один эндпоинт
  «импорт + сверка». Я разделила их на два действия: иначе после внесения расхождений в PG
  (`inject`) импорт сразу перезаписал бы их данными из 1С, и сверка всегда показывала бы
  «расхождений нет».
- **Лицензия 1С.** Агент предложил активировать комьюнити-лицензию второй раз внутри
  контейнера. Я отказалась: лицензия выдаётся на один компьютер, а контейнер работает на том
  же Mac. Формулировку раздела о лицензии в README задала я.
